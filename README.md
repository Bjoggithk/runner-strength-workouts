# Runner Strength Workouts

Mobile-friendly static website for rotating strength workouts tailored for runners.

## Features
- Choose Gym A/B/C or Home A/B/C
- Step through exercises one-by-one
- Sets & reps + written instructions
- Image/GIF support (easy to update)
- Progress bar
- Mobile-first design

## How to use
1. Enable GitHub Pages (Settings → Pages → Deploy from main branch / root)
2. Visit the published URL on your phone
3. Select a workout and progress through the exercises

## Expanding later
- Edit `workouts.js` to add exercises, change sets/reps, or swap image URLs (replace the placeholder Tenor-style links with real GIF URLs from Tenor, Giphy, or your own hosted files)
- Add new workouts by extending the `workouts` object
- Future ideas: timers, rest periods, logging completed sets, dark/light theme toggle, offline support (PWA)
